JavaScript · 브라우저에서 실행

코드를 바꾸고 Run 또는 ⌘/Ctrl + Enter를 누르세요.

const numbers = [1, 2, 3, 4];
const doubled = numbers.map((number) => number * 2);
console.log(doubled.join(", "));

Kotlin · 동일한 문서, 로컬 실행기

이 블록은 웹에서도 동일하게 편집되지만 서버리스 웹 빌드에서는 실행하지 않습니다.

fun main() {
    val numbers = listOf(1, 2, 3, 4)
    println(numbers.map { it * 2 }.joinToString(", "))
}
